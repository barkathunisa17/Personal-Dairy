# My Little Memory Journal

## Run it (first time)
1. Open this folder in VS Code.
2. Open the terminal in VS Code (Terminal > New Terminal).
3. Run: npm install
4. Run: npm run dev
5. Click the link it shows (usually http://localhost:5173)

Your diary data is currently saved in YOUR browser only (localStorage),
inside src/storageAdapter.js. See the setup guide from Claude for how
to connect a real database (Supabase) next.
